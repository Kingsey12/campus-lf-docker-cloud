# Lost & Found Campus App

A simple web app for campus communities to report and discover lost/found items.

## Features

- Upload lost or found items with details and optional image
- Contact owner via email/phone if available
- Built-in chat per item for quick communication
- Item categorization and filters by category/type
- Search by title, location, or category

## Run

1. Open `index.html` in a browser.
2. Start posting items.

## Notes

- Data is saved in browser local storage.
- Chat is local demo chat (not connected to a real backend).
