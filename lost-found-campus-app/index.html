Multi-Tier Cloud System Architecture

Tier 1 • Client Layer
Single Page App (SPA)
Responsive Web UI with Glassmorphism, BroadcastChannel realtime sync, and client-side caching.
Tier 2 • Edge / Auth
Cloud Auth & Security
Token-based student session authentication, role-based access control (Student vs Campus Admin).
Tier 3 • Database
NoSQL Cloud DB (Firestore)
Document-oriented collections (`items`, `chats`), real-time snapshots with low-latency updates.
Tier 4 • Storage
Cloud Object Storage
Cloudinary / Firebase Storage CDN for high-resolution item media and automated compression.

💡 Designed specifically for university coursework requirements in Cloud Design and Implementation.

service cloud.firestore {
  match /databases/{database}/documents {
    // Anyone can read items
    match /items/{itemId} {
      allow read: if true;
      allow create: if request.auth != null || request.resource.data.title != null;
      allow update, delete: if request.auth.uid == resource.data.creatorId 
                            || request.auth.token.role == 'Campus Admin';
    }
    // Per-item encrypted cloud chat
    match /chats/{itemId}/messages/{msgId} {
      allow read, write: if true;
    }
  }
}
